Создай программу на Python для обработки данных электронного уровня при контроле плоскостности поверочных плит (чугунных и гранитных).
1. Геометрия плиты и сетка точек
Задаваемые габариты плиты: длина × ширина в мм, по умолчанию 1000 × 630 мм.
Отступ первой/последней измерительной точки от края плиты, по умолчанию 20 мм.
Равномерная сетка разбиения поверхности: N интервалов по длинной стороне и M интервалов по короткой. По умолчанию 6 × 6 интервалов → 7 × 7 = 49 точек.
Нумерация:
по длинной стороне (ось X) — цифры 0…6, отсчёт от 0;
по короткой стороне (ось Y) — буквы A…G, отсчёт от A.
Точка A0 — левый нижний угол, координаты (20, 20).
Точка A6 — правый нижний угол, координаты (980, 20), т.е. X_i = отступ + i * (длина − 2*отступ) / N.
Аналогично Y_j = отступ + j * (ширина − 2*отступ) / M, где j=0 ↔ буква A.
Все параметры должны задаваться через конфигурационный файл (JSON/YAML/TOML) либо аргументы командной строки.
2. Входные данные
Измерения считываются из текстового файла. Формат — одна строка на один профиль:
<начальная точка> <конечная точка> <время измерения> <шаг измерения> <массив углов>
Пример: A0 A6 2026-11-18T14:32 160 0.5 0.4 0.3 0.35 0.42 0.5
Требования к парсеру:
Поддержка разделителей пробел/табуляция; массив значений через запятую или пробел.
Понятные сообщения об ошибках с указанием номера строки.
Допуск расхождения фактического числа точек профиля с расчётным ±1 с предупреждением.
3. Математика обработки
Перевод углов θ (мкм/м) в перепады высот за шаг: Δh_k ≈ step_mm * θ_k * 1e-6 (мкм).
Восстановление высот узлов методом наименьших квадратов (МНК) по замкнутой сети профилей (B * h = d).
Построение профилей линий с равномерной интерполяцией между узлами.
Аппроксимация плоскости методом наименьших квадратов. Плоскостность = размах отклонений от этой плоскости (по ISO 8512 / DIN 876).
Расчет прямолинейности диагоналей и линий сетки.
4. Результаты и вывод
Таблица высот 7×7 узлов в мкм.
Карта отклонений (heatmap + contour) с цветовой шкалой, сохранение в PNG/PDF.
Графики профилей всех линий и диагоналей.
Сводка: плоскостность (F) в мкм, направление перекоса, сравнение с допусками по классам точности (00, 0, 1, 2).
Экспорт результатов в CSV, JSON и HTML-отчет.
Вывод сводки в консоль.
